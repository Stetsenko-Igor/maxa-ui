# MaxaLogo Implementation Plan

> **Correction:** This plan records the original implementation and is superseded by the approved contract in `docs/superpowers/specs/2026-08-24-maxa-logo-design.md`. The final logo is white-only and both `A` apexes are connected. The prototype SVG cited below is not an approved source.

> **Implementation mode:** Execute inline in the current workspace. Preserve the existing uncommitted Neutral/75 work and use passing tests as task checkpoints instead of creating mixed commits.

**Goal:** Add the official MAXA wordmark as a reusable, documented, accessible `MaxaLogo` component in `@maxa/ui`, with dark and light appearances and exact source geometry.

**Architecture:** Render the approved four-path wordmark as an inline SVG React component. Keep brand colors fixed through two component tokens in `@maxa/tokens`, expose normal SVG sizing/props, and document the component alongside the existing catalog. Replace the two fake text logos in the Toolbar Menus pattern with the real component.

**Tech stack:** React 19, TypeScript, CSS custom properties, Vitest, Testing Library, jest-axe, Next.js docs.

### Step 3: Implement `MaxaLogo`

Use the approved API and official geometry:

```tsx
import * as React from "react"
import { cn } from "../../lib/cn.js"
import "./maxa-logo.css"

export type MaxaLogoAppearance = "dark" | "light"

export interface MaxaLogoProps extends React.SVGAttributes<SVGSVGElement> {
  appearance?: MaxaLogoAppearance
  decorative?: boolean
}

export const MaxaLogo = React.forwardRef<SVGSVGElement, MaxaLogoProps>(
  function MaxaLogo(
    {
      appearance = "dark",
      decorative = false,
      width = 120,
      height,
      className,
      style,
      role,
      "aria-label": ariaLabel,
      "aria-hidden": ariaHidden,
      ...props
    },
    ref,
  ) {
    return (
      <svg
        {...props}
        ref={ref}
        className={cn("maxa-logo", className)}
        data-appearance={appearance}
        viewBox="0 0 1518 262"
        preserveAspectRatio="xMidYMid meet"
        width={width}
        height={height}
        role={decorative ? undefined : (role ?? "img")}
        aria-label={decorative ? undefined : (ariaLabel ?? "MAXA")}
        aria-hidden={decorative ? true : ariaHidden}
        focusable="false"
        style={height === undefined ? { height: "auto", ...style } : style}
      >
        <g fill="currentColor">
          <path d="M0 0h38l124 170L279 0h38v262h-36V49L173 221h-21L36 50v212H0z" />
          <path d="M391 262h46L556 31 533 0zM556 31l117 231h49L579 0zM513 164h110l17 34H531z" />
          <path d="M795 0h64l254 262h-64zM1034 0h56L853 262h-56z" />
          <path d="M1187 262h46l119-231-23-31zM1352 31l117 231h49L1375 0zM1309 164h110l17 34h-109z" />
        </g>
      </svg>
    )
  },
)

MaxaLogo.displayName = "MaxaLogo"
```

Add CSS that makes the SVG responsive and maps appearances to fixed component tokens:

```css
.maxa-logo {
  display: block;
  max-width: 100%;
  flex: 0 0 auto;
  color: var(--maxa-logo-color-dark);
}

.maxa-logo[data-appearance="dark"] {
  color: var(--maxa-logo-color-dark);
}

.maxa-logo[data-appearance="light"] {
  color: var(--maxa-logo-color-light);
}
```

Export the component from its folder barrel.
